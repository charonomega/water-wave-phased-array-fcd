# 水波阵列控制与 FCD 波场分析系统

**(Water Wave Array Control & FCD Analysis System)**

## 📌 项目简介 (Project Overview)

本项目是一个集成了**硬件通信控制**与**流体力学计算成像**的综合物理实验平台。系统主要由两大核心模块协同工作：

1. **下位机扬声器阵列控制系统**：通过串口与多达 24 通道（3块控制板联级）的超声/扬声器阵列进行高速通信，实现波形参数（振幅、相位、周期）的精准下发。系统内置跨板绝对物理量纲的 LUT 校准映射，用以消除硬件容差，并支持全自动的声光同步定标轮播。
2. **基于 FCD 的偏折术波场分析系统**：利用迈德威视 (MindVision) 工业相机捕捉水面下方的棋盘格形变图像 (Fast Checkerboard Demodulation)。通过先进的特征空间 Sylvester 代数积分器、时均静态本底分离技术以及 Navier-Stokes 梯度修复算法，高精度反演无伪影的水面三维高度场与二维位移场。

## 📂 核心文件结构与代码解析 (File Structure & Modules)

### 1. 中央硬件控制前端 (`main_gui_circ.py`)

系统的主控中枢，提供了一个仿 LabVIEW 风格的高效图形化交互界面。

* **全阵列参数矩阵**：动态生成支持单板（8通道）至 3 板联级（24通道）的操控矩阵。支持对所有通道的幅度、相位、周期与使能开关进行并发下发。
* **跨板 LUT 补偿引擎** (`_apply_lut_calibration`)：加载定标 JSON 后，自动提取全局最大物理振幅 (`Global_Max_Amp_mm`) 作为绝对锚点，通过逆向非线性插值，将用户输入的无量纲比例转化为精准的补偿驱动电压，实现 24 喇叭物理高度的绝对一致。
* **自动定标流** (`start_carousel`)：一键启动全阵列自动定标，精准控制单通道激发、等待水面稳定、触发相机采集及数据冷却落盘的时序闭环。

### 2. 阵列通信后端 (`speaker_controller.py`)

负责与下位机（如 Arduino / STM32 主控板）进行串口指令的封装与交互。

* **防死锁初始化**：在建立串口连接时显式关闭硬件流控 (`dsrdtr=False, rtscts=False`)，并强行拉低 DTR/RTS 电平，防止触发下位机不必要的自动重启。
* **协议指令封装**：实现了 `write_waveform_params`（写入波形）、`write_channel_enables`（通道使能）、`save_configuration`（保存配置）等多种底层指令的序列化，以及包含 `#`、`?`、`E` 等状态符的通信返回报文解析。

### 3. 工业相机驱动封装 (`camera_controller.py`)

针对迈德威视 SDK 的高级面向对象封装，提供极端稳定的机器视觉捕获能力。

* **物理帧率节拍器** (`_grab_loop`)：内置严格的 `time.sleep` 补偿流控机制。针对主机处理速度过快的问题进行动态延时补偿，确保指定 FPS 下的高频序列抓拍绝对均匀、不丢帧。
* **安全落盘机制** (`wait_and_save`)：使用 `%04d` 的零填充格式化命名规范（如 `frame_0001.tiff`），将独立内存中缓存的 TIFF 序列批量异步写入硬盘，彻底杜绝后续 FCD 时序解析时发生文件名排序错乱的问题。

### 4. FCD 波场解调分析前端 (`fcd_gui.py`)

独立的波场解析上位机软件界面。

* **标定交互与任务路由**：提供交互式的选取功能提取有效像素边框。封装了单帧波场解析、连续帧批处理分析、点波源测距以及斯格明子拓扑 Q 值计算等核心任务的触发入口。

### 5. 流体力学计算引擎 (`fcd_backend_syl_circ.py`)

本系统的核心数学与物理引擎，将偏折术图像反演为水面绝对物理场。

* **智能边界与遮挡处理** (`_get_smooth_occlusion_mask`)：独创针对喇叭等遮挡物的拓扑处理。使用 OpenCV 的 Inpainting 算法在频域积分前丝滑填补伪造梯度，消灭积分器在边界处的伪影隆起。
* **Sylvester 极速特征空间积分** (`_fftinvgrad`)：抛弃会引发周期性卷叠伪影的传统 FFT 积分。利用有限差分矩阵的对称性，在特征空间进行 $O(N^2)$ 的标量极速求解，获得严苛物理边界下的高精度三维高度场。
* **时均场静态本底分离法** (`process_sequence`)：针对短序列（如 63 帧）分析，提取时间平均场并施加绝对刚性的 2 阶曲面拟合。在不伤害高频水波的前提下，像推土机一样全局剥离由相机微震动和镜头呼吸效应引发的大尺度“积分漂移大碗”。
* **靶向自动定标输出** (`run_calibration`)：自动搜索极值幅度中心点执行 Sine Fitting。在输出 `speaker_lut_calibration.json` 补偿文件时，自动按板卡数量（每板 8 通道）切片生成独立配置，确保控制前端能够无冲突读取。

### 6. 相机底层接口 (`mvsdk.py`)

迈德威视官方提供的 Python 接口层，利用 `ctypes` 桥接操作系统的相机 C/C++ 动态链接库。

## 🚀 基础操作与实验流程 (Workflow)

1. **硬件连接启动**：
* 确保控制主板通过 USB 接入，迈德威视相机通过网线/USB 3.0 正确连接至电脑。


2. **操控水波阵列 (`main_gui_circ.py`)**：
* 运行主控 GUI，在顶部选择对应串口并点击“🔌连接串口”，随后点击“📸连接相机”。
* 若有预先定标好的校准文件，分别为 1~3 板加载对应的 `.json`，并勾选“全局启用定标补正”。
* 调整相应通道的幅度与相位参数，点击“▶ 执行”，下发驱动指令。


3. **采集光场数据**：
* 在界面设置合适的相机曝光和帧率。利用相机模块的录制功能，捕获稳定的水波序列。


4. **反演物理场 (`fcd_gui.py`)**：
* 启动波场分析 GUI。填入无波静止时的“基准参考图”路径，以及包含形变波纹的实验图像/序列路径。
* 执行“选取区域”裁切掉无用水槽边缘，点击相应的解析按钮，即可自动生成带严谨物理标尺的高度场、三维位移场及拓扑分析图。
